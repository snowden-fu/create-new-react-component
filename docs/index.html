React component generator

Create React components from one command.

Generate JavaScript or TypeScript React components with matching index files, optional CSS or SCSS modules, built-in component templates, and custom template support.

Install View on npm
5 component templates
2 language targets
CSS and SCSS modules

Install

Use it globally or add it to a project.

The CLI starts with an interactive prompt, validates component names, and writes a component directory in your current working folder. 

npm install -g create-new-react-component

create-new-react-component

Templates

Choose the component shape you need.

Functional

Classic named function component with optional props.

Arrow

Concise `const Component = () => {}` output.

Class

React class component scaffold for legacy projects.

Memoized

Wrap components with `React.memo` for stable render paths.

ForwardRef

Create a component ready to pass refs through to a DOM node.

Custom

Load your own reusable template file or template directory.

Workflow

Predictable files, ready to edit.

Generated components follow a small folder convention that keeps imports tidy, keeps styles near the component, and works across JavaScript and TypeScript projects.
